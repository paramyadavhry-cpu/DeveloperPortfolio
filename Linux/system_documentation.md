# System Documentation (Linux)

## Overview
This document describes the Linux commands I used to build my system profile and the files generated in this folder.

## Commands Used

| Command | Purpose |
|---|---|
| `uname -a` | Displays system and kernel information |
| `whoami` | Shows the current logged-in user |
| `pwd` | Prints the current working directory |
| `ls -la` | Lists all files with detailed information |
| `df -h` | Shows disk space usage in human-readable format |
| `free -h` | Shows memory (RAM) usage |
| `ps aux` | Lists all running processes |

## Files in This Folder

- `system_profile.txt`: System profile of my machine
- `ls_output.txt`: Output of the `ls` command
- `processes.txt`: List of running processes
- `commands.sh`: Script that runs the commands above

## Conclusion
These commands helped me understand how to inspect system details, manage files and monitor running processes in Linux.
